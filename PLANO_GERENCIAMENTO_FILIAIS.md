# Gerenciamento de Links de Filiais (Matriz -> Filial)

## Objetivo
Criar uma interface na Matriz para vincular o ambiente da estação (Kiosk) à loja correspondente, gerando um identificador/link exclusivo de acesso.

## Funcionalidades
- **Cadastro de Link**: Associar um ID único de Filial a uma Loja existente.
- **Link de Acesso**: Gerar o link de acesso que será configurado no navegador da Filial (Ex: `https://radio.gmais.com/filial/[ID_FILIAL]`).
- **Gestão de Links**: Listar, editar ou revogar links ativos.
