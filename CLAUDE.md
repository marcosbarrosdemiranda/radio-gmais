## VoiceStudio TTS (Integração Local)
Para utilizar o motor de voz local VoiceStudio como alternativa ao ElevenLabs:
1. Certifique-se de que o aplicativo VoiceStudio (https://github.com/debpalash/VoiceStudio) esteja rodando na máquina (Matriz ou Filial).
2. O Backend API do VoiceStudio deve estar ouvindo na porta padrão `3900`.
3. No front-end (Locutor Virtual), selecione o motor "VoiceStudio" para realizar a geração offline sem custos de API.
